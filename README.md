#  Vue Post Dashboard

Учебный проект для отработки архитектуры Vue 3 + TypeScript. Реализован функционал фильтрации, создания постов и работы с API через сервисный слой.

##  Ключевые моменты
* **Composition API:** Использование composables (`usePosts.ts`) для управления состоянием.
* **TypeScript:** Строгая типизация данных.
* **API Service:** Выделенный слой запросов для чистого кода.
* **Mock Server:** Прототипирование с `json-server`.
